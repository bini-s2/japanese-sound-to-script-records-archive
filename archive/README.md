## 보존 원칙

1. 기존 22개 파일(README, AGENTS, 기획 문서 19개, 작업 로그 1개)을 원본 Git blob SHA로 **내용 변경 없이** `archive/legacy/` 아래에 정리했습니다.
2. Git 커밋 이력은 삭제하거나 재작성하지 않았습니다. 초기 연구와 작업 과정의 기록은 이 저장소의 기존 커밋을 통해 확인할 수 있습니다.
3. 원본 문서는 작성 시점의 기획·설계·진행 상태를 반영하며, **현재 사이트 기능이나 최신 운영 규칙과 일치하지 않을 수 있습니다.**
4. 실제 라이브 서비스의 소스·학습 데이터·내부 작업 기준은 별도 **Private** 저장소로 통합되어 있습니다. 이 공개 저장소에는 새 비공개 코드를 추가하지 않습니다.

최신 공개 서비스 소개는 [README](../README.md)와 [Product story](../showcase/PRODUCT-STORY.md)를 참고해 주세요.
