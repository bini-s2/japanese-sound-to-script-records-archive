## Overview

**Japanese Sound to Script**는 일본어를 듣고 뜻은 어렴풋이 알지만, 실제 **히라가나·가타카나·한자 표기**와 연결하기 어려운 학습자를 위한 서비스입니다.

일본어 발음이 기억날 때, 한글로 들린 소리를 입력하고 **일본어 원문 → 읽기 → 한국어 뜻 → 복습**으로 이어갈 수 있도록 설계했습니다.

```text
기억나는 소리  →  일본어 원문 찾기  →  읽기와 뜻 확인  →  저장과 복습
   Sound              Script             Meaning          Recall
```

### 이런 상황에서 시작했어요

- 애니메이션이나 J-POP에서 들은 말이 무슨 표현인지 궁금할 때
- `카와라나이 모노`는 익숙하지만 `変わらないもの`를 바로 읽기 어려울 때
- `고료`와 `고리요`처럼 들리는 소리와 실제 표기가 다를 때
- 따로 외운 단어보다 **내가 궁금해서 찾았던 표현**을 다시 공부하고 싶을 때

## Main features

| 기능 | 무엇을 할 수 있나요? |
| --- | --- |
| **소리로 검색** | 한글로 기억한 일본어 발음에서 원문·읽기·뜻 후보를 비교합니다. 요음·장음 등 듣기와 표기의 차이도 고려합니다. |
| **문자 학습** | 히라가나·가타카나와 자주 쓰는 한자를 함께 익힙니다. |
| **랜덤 퀴즈** | 문자·단어·문장을 무작위 또는 상황별로 연습합니다. |
| **복습하기** | 알았어요/헷갈려요 피드백으로 다시 볼 표현을 정리합니다. |
| **북마크** | 궁금했던 표현을 저장하고 다시 확인합니다. |
| **JLPT N5 베타** | 문법·어휘·독해·청해 등 기초 학습을 연습합니다. |

## UX direction

**1. 검색은 사전 암기가 아니라 ‘들었던 소리’에서 시작합니다.**  
일본어 표기를 몰라도 검색할 수 있게 하고, 발음이 애매한 경우 선택 가능한 후보를 제공하는 것을 지향합니다.

**2. 원문·발음·의미를 먼저, 세부 학습은 그다음에 보여줍니다.**  
처음 보는 검색 결과에서 무엇을 선택해야 하는지 쉽게 알 수 있도록 정보의 순서를 정리합니다.

**3. 정답 확인에서 끝나지 않고 복습으로 연결합니다.**  
사용자가 궁금해서 찾은 표현이 이후 학습 콘텐츠가 되도록 구성했습니다.

자세한 설계 과정은 **[프로젝트 UX 이야기](./showcase/PRODUCT-STORY.md)**에서 볼 수 있습니다.
