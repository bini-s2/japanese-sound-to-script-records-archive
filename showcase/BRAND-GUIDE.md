# Tomobi. — 미니 브랜드 가이드

> 들었던 소리가, 아는 말이 되는 순간.

## 1. 브랜드 코어

| 항목 | 원칙 |
| --- | --- |
| 공식 표기 | **Tomobi.** (대문자 T, 소문자 omobi, 마지막 마침표 포함) |
| 한국어 발음 | 토모비 |
| 어원 | 일본어 **灯火（ともしび）**, 작은 등불에서 착안 |
| 브랜드 역할 | 들은 일본어의 표기와 뜻을 이해하도록 돕는 작고 친절한 학습 도구 |
| 성격 | 따뜻함 · 호기심 · 명료함 · 절제 |
| 슬로건 | **들었던 소리가, 아는 말이 되는 순간.** |

노래 가사나 개인적인 영감의 상세한 배경은 공개 브랜드 카피에 그대로 옮기지 않습니다.

## 2. 로고 타입 3가지 방향

| 시안 | 형태 | 인상 | 판단 |
| --- | --- | --- | --- |
| **A. Signature (현재 적용)** | `Tomobi`는 잉크 블랙, **마침표(.)만 오렌지**. 26px의 부드러운 Bold 산세리프, 자간 -0.06em | 간결하고 친근한 프로덕트 워드마크 | **현재 운영용** |
| **B. Editorial (비교안)** | 같은 색 규칙을 유지하고 굵기를 Medium으로, 자간을 조금 여유 있게 | 차분하고 프리미엄한 에디토리얼 인상 | 랜딩·소개 페이지 비교용 |
| **C. Soft Geometric (비교안)** | 같은 색 규칙으로 둥근 `o`와 부드러운 획 끝을 강조한 기하학적 커스텀 | 귀엽지만 유치하지 않은 친근함 | 커스텀 로고 개발 시 참고 |

B와 C는 **방향 제안**이며, 별도 폰트 파일 또는 확정 벡터 로고를 제작·적용했다는 의미는 아닙니다.

## 3. 워드마크 비율

- **Desktop:** 헤더 높이 72px, 로고 26px, font weight 850, tracking -0.06em
- **Mobile:** 헤더 높이 64px, 로고 23px. 보조문구 숨김
- **보조문구:** Desktop 10px, 로고 아래 4px 간격. `들린 소리에서 이해로`
- **시각적 강조:** `Tomobi` 전체는 잉크 블랙. 마지막 `.`만 오렌지. `To`에 별도 색상 강조 금지
- **Favicon:** 잉크색 `To` + 오렌지 점
- **Minimum clear space:** 워드마크 대문자 T의 높이 절반만큼의 여백. 마침표 단독 줄바꿈 금지

## 4. 컬러 시스템

| 역할 | HEX | 사용 예 |
| --- | --- | --- |
| Signature Orange | `#FF6B35` | 브랜드 포인트, 장식적인 그래픽 |
| Action Orange | `#C74415` | 오렌지 마침표, 흰 글자 버튼 |
| Ink | `#111827` | 워드마크, 헤드라인, 본문 |
| White | `#FFFFFF` | 기본 배경 |
| Soft Orange | `#FFF7F2` | 포인트가 필요한 연한 영역 |

접근성 확보를 위해 작은 텍스트와 CTA는 대비가 높은 Action Orange를 우선하며, 상태를 오로지 색상으로 설명하지 않습니다.

## 5. UI / 모션 / 카피

- 직접적인 불꽃·별 캐릭터 대신, **작은 점과 상태 변화**로 '이해의 불빛'을 은유합니다.
- 기존의 **“방금 들은 일본어, 무슨 뜻이지?”**라는 기능 중심 메인 카피를 유지합니다.
- 감정적 세계관을 지나치게 강조하지 않고 실제로 도움이 되는 검색 정확도와 읽기 쉬운 결과 UI를 우선합니다.
- 검색 → 표기 → 의미 → 복습의 학습 흐름과 익숙한 UI 패턴을 유지합니다.

## 6. 구현 범위

**A 방향만 실제 사이트 헤더에 적용됨.** 
도메인과 기술 저장소명에는 이전 프로젝트명이 남아 있으며, 브랜드명 개편만으로 변경하지 않았습니다.
